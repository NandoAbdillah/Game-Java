## About Project

**Sukma Gowong** adalah game **3D Horror Adventure** yang terinspirasi dari folklore dan nuansa mistis Indonesia. Project ini dibangun dengan **Java** dan **LibGDX**, dengan fokus pada pengalaman eksplorasi yang tegang, atmosfer gelap, audio yang imersif, serta gameplay survival yang memberi tekanan emosional kepada pemain.

Pemain akan menjelajahi dunia yang dipenuhi aura supranatural, mengumpulkan relik penting, menghindari entitas berbahaya, serta mengungkap misteri yang mengikat dunia permainan. Selain sebagai game, project ini juga menjadi implementasi nyata dari konsep **Pemrograman Berorientasi Objek (OOP)**, arsitektur game, pengelolaan aset 3D, audio system, dan manajemen state secara terstruktur.

Tujuan utama project ini adalah:

* menghadirkan folklore Indonesia dalam bentuk media interaktif 3D;
* menunjukkan penerapan OOP yang nyata dalam project game;
* melatih integrasi antara gameplay, visual, audio, dan UI;
* membangun pengalaman horror yang sinematik, ringan, dan terarah.

## Gameplay Overview

Pemain memulai permainan di dunia yang suram dan penuh tanda-tanda mistis. Eksplorasi menjadi inti utama: berjalan, mengamati lingkungan, mengambil item, membaca petunjuk, dan bertahan dari ancaman yang terus mengintai. Setiap area dirancang untuk memberi rasa tidak aman, sehingga pemain harus memperhatikan suara, cahaya, dan arah gerak musuh.

Dalam game ini, progres pemain ditentukan oleh kemampuan menjelajah dan memahami dunia. Semakin jauh pemain masuk, semakin intens pula atmosfer horror yang muncul melalui AI musuh, visual environment, dan efek audio yang berubah dinamis.

## Story Overview

Kisah Sukma Gowong berakar pada nuansa folklore Indonesia yang kelam. Dunia permainan menghadirkan misteri, relik, dan entitas gaib yang tidak sepenuhnya bisa dijelaskan. Pemain dibawa ke perjalanan yang bukan hanya soal bertahan hidup, tetapi juga soal mengungkap potongan-potongan cerita yang tersembunyi di balik teror.

Narasi dibuat untuk memberikan rasa penasaran sekaligus tekanan emosional. Setiap area, item, dan suara menjadi bagian dari petunjuk yang mengarah pada rahasia di balik kejadian yang menimpa dunia permainan.

## OOP Implementation

Project ini dirancang untuk menunjukkan implementasi **OOP** secara nyata, bukan hanya teori. Struktur class dibuat agar mudah dibaca, mudah di-extend, dan aman untuk pengembangan fitur baru.

### 1. Inheritance

Inheritance dipakai untuk mengurangi duplikasi kode dan membangun hierarki objek yang konsisten.

Contoh konsep:

* `Entity` sebagai base class
* `Player` sebagai turunan
* `Enemy` sebagai turunan
* `Item` atau `Relic` sebagai turunan lainnya

Dengan inheritance, class turunan mewarisi properti dasar seperti posisi, rotasi, collision, dan update logic umum.

### 2. Encapsulation

Data penting disembunyikan di dalam class dan hanya diakses melalui method yang terkontrol.

Contoh penerapan:

* `health` tidak diubah sembarangan dari luar class
* `state` musuh diganti lewat method tertentu
* `position`, `speed`, dan `cooldown` dikelola agar alur logika tetap aman

Pendekatan ini menjaga game logic tetap stabil dan mencegah bug akibat perubahan state yang liar.

### 3. Polymorphism

Polymorphism digunakan agar berbagai objek dapat diperlakukan dengan cara yang sama melalui tipe induk.

Contoh:

* semua entity dipanggil melalui `update()`
* setiap object memiliki perilaku masing-masing
* entity manager cukup memanggil satu interface perilaku umum

Hasilnya, sistem menjadi lebih fleksibel dan mudah dikembangkan.

### 4. Abstraction

Abstraction dipakai untuk menyembunyikan detail teknis yang rumit.

Contoh:

* screen management
* asset loading
* audio playback
* world rendering

Layer luar cukup memanggil method sederhana, sementara detail OpenGL, render cycle, dan manajemen file ditangani di dalam class masing-masing.

### Implementasi Dalam Struktur Game

Beberapa class inti yang menjadi contoh penerapan OOP:

* `Entity` → basis objek dunia
* `Player` → karakter utama
* `Enemy` → musuh dengan state behavior
* `Item` → objek yang bisa diambil
* `GameScreen` → kontrol layar permainan
* `GameplayManager` → pengatur alur gameplay
* `AudioManager` → pengatur suara dan musik
* `GameAssets` → pengelola asset berat
* `WorldManager` → pengatur world, environment, dan collision
* `SceneRenderer` → penggambar visual utama

---

## Design Patterns

Beberapa design pattern relevan yang digunakan atau sangat cocok dengan struktur project ini:

### Singleton Pattern

Dipakai pada class seperti `AudioManager` atau `GameAssets` agar hanya ada satu instance aktif untuk resource berat.

### Manager / Facade Pattern

Dipakai pada `GameplayManager` atau `WorldManager` untuk memusatkan koordinasi antar sistem.

### State Pattern

Cocok untuk AI musuh yang memiliki mode berbeda seperti idle, patrol, chase, attack, dan dead.

### Component Pattern

Berguna jika ingin memecah perilaku entity menjadi bagian-bagian kecil yang bisa dipakai ulang.

## Project Structure

```text
src/
├── core/
│   ├── assets/          # Cache dan pengelolaan aset 3D, audio, dan font
│   ├── audio/           # AudioManager, track, dan efek suara
│   ├── camera/          # Sistem kamera dan kontrol view
│   ├── entity/          # Player, Enemy, Item, Relic, Props
│   ├── input/           # Keyboard, mouse, dan kontrol lainnya
│   ├── managers/        # GameplayManager, WorldManager, system controller
│   ├── screens/         # MainMenu, GameScreen, Credits, Loading
│   ├── transitions/     # Fade transition dan layar peralihan
│   ├── ui/              # Scene2D UI, HUD, menu, dialog
│   └── world/           # Environment, fog, lighting, weather, sky
└── lwjgl3/
    └── src/             # Desktop launcher
```

### Penjelasan singkat folder

* **assets** → menangani file berat dan pengelolaan resource
* **audio** → mengatur musik, ambience, dan SFX
* **camera** → mengatur sudut pandang pemain
* **entity** → semua objek interaktif di dunia game
* **input** → pemetaan input pemain
* **managers** → pusat kendali sistem
* **screens** → semua layar game
* **transitions** → efek perpindahan layar
* **ui** → elemen antarmuka
* **world** → environment dan atmosfer

## Installation Guide

### Prasyarat

* JDK 17 atau versi yang kompatibel
* Android Studio terpasang
* Git terinstal
* GPU / driver yang mendukung OpenGL sesuai kebutuhan LibGDX

### Langkah Instalasi

1. Clone repository:

```bash
git clone https://github.com/USERNAME-ANDA/SukmaGowong.git
cd SukmaGowong
```

2. Buka project di Android Studio.
3. Tunggu proses **Gradle Sync** selesai.
4. Pastikan dependencies berhasil terunduh.
5. Jalankan desktop launcher dari module `lwjgl3`.

---

## How To Run

### Windows

* Buka project melalui Android Studio.
* Jalankan target desktop launcher atau konfigurasi `Lwjgl3Launcher`.

### Linux

* Pastikan JDK dan permission file sudah sesuai.
* Buka project lalu jalankan launcher desktop.

### Desktop Launcher

* Cari kelas `Lwjgl3Launcher`.
* Klik **Run**.
* Tunggu game terbuka dalam window desktop.

## Development Journey

Pengembangan **Sukma Gowong** dimulai dari kebutuhan untuk membuat game horror 3D yang tidak hanya menarik secara visual, tetapi juga kuat secara struktur software. Selama prosesnya, tim mempelajari bagaimana membangun arsitektur game yang rapi, mengelola asset 3D, menjaga performa rendering, serta menyusun sistem gameplay yang konsisten.

Beberapa bagian pengembangan yang paling berpengaruh antara lain:

* pengelolaan asset agar tidak boros memori;
* pembuatan AI musuh yang responsif;
* integrasi audio untuk memperkuat atmosfer;
* penyesuaian UI supaya tetap jelas di layar gelap;
* penyusunan credit scene dan presentasi visual yang terasa sinematik.

Project ini tumbuh melalui banyak revisi. Setiap revisi bukan hanya memperbaiki tampilan, tetapi juga memperjelas bagaimana sistem harus bekerja sebagai satu kesatuan.

## Challenges & Lessons Learned

### Tantangan

* rendering 3D dan optimasi performa
* sinkronisasi asset visual dan audio
* struktur OOP agar tidak berantakan saat project bertambah besar

* audio dan lighting punya pengaruh besar terhadap horror atmosphere
* dokumentasi project penting untuk kolaborasi tim
* project game terlihat sederhana dari luar, tetapi sangat kompleks di dalam
